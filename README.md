# NJOKA DAMES — Version Windows

**NJOKA DAMES** est un jeu de dames internationales sur plateau 10×10.

## Fonctionnalités

- Jeu local à deux joueurs.
- Jeu contre une intelligence artificielle.
- Cinq niveaux : Facile, Moyen, Difficile, Expert et Maître.
- Prises obligatoires et prises maximales.
- Prises multiples et dames volantes.
- Fonctionnement hors ligne.

## Configuration

La version Windows est développée en Java 21 avec Swing.
Elle utilise le moteur de jeu et l'intelligence artificielle du projet NJOKA DAMES.
